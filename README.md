# ColorSwitcher (Qt)

Лабораторная работа №3 по кроссплатформенному программированию.
Демонстрация работы QTimer, лямбда-слотов и динамических соединений.

## Возможности
- Переключение цвета холста по таймеру (режимы: цикл, случайный, мигание).
- Обработка кликов мыши через mousePressEvent.
- Динамическое создание кнопок-цветов и разрыв соединений.
- Переподключение обработчиков сигнала на лету.

## Сборка
1. Открыть проект в Visual Studio 2022 с Qt VS Tools.
2. Выбрать конфигурацию Debug.
3. Собрать (Ctrl+Shift+B) и запустить (F5).
